Claude (gold)

Hooks are HTTP/command callbacks with JSON stdin/body. Status line is a separate command fed a JSON payload on a refresh cadence — chopsticks’ only live CTX source for Claude.

Codex

App Server JSON-RPC over WS-in-UDS: client methods + server notifications + item types. Permissions arrive as structured server requests, not hooks.

ACP / Grok

ACP = Agent Client Protocol v1 (session/* + session/update). Grok = ACP + native updates.jsonl dual-source (hooks/turn extensions in the log).
